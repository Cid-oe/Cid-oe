## ⚡ Core Technical Pillars

### 1. AI Agent Reliability & Constrained Execution
- **[TraceLens](https://github.com/Cid-oe/tracelens)**: Local-first evaluation and regression testing framework for AI agents (`pip install tracelens`). Provides inspectable traces, task-level bootstrap confidence intervals, and CI gates with `pass@k` / `pass^k` metrics.
- **[go-dav-os Agent Subsystem](https://github.com/Cid-oe/go-dav-os)**: Engineered a "Minimum Working Agent" inside an x86_64 freestanding Go OS kernel. Replaces arbitrary shell evaluation with typed actions, strict allowlists, and execution safety gates.
- **[AgentLink](https://github.com/Cid-oe/AgentLink)**: Persistent, permissioned, and recoverable execution infrastructure for long-running AI workers with checkpoints and bounded authority.

### 2. High-Performance Developer Tooling & Security
- **[RTK (Rust Token Killer)](https://github.com/Cid-oe/rtk)**: High-performance CLI proxy cutting 60–90% of LLM token consumption by filtering bash outputs before LLM ingestion. Deterministic output ordering.
- **[zero-shelter](https://github.com/Cid-oe/zero-shelter)**: Local-first vulnerability triage tool turning noisy dependency scanner output into an actionable, deterministic fix list without runtime LLM overhead.
- **[CellFence](https://github.com/Cid-oe/CellFence)**: CI guardrails enforcing architecture boundaries and static analysis checks on AI-generated pull requests.

### 3. Production Infrastructure & Open Data
- **[CERN Open Data Portal (`cernopendata-portal`)](https://github.com/cernopendata/cernopendata-portal)**: Upstream contributor to research data pipelines. Resolved Celery worker process-fork race conditions in `invenio-queues`, implemented DataCite DOI metadata validations, and streamlined background worker logging.
- **[Omarchy Linux (`basecamp/omarchy`)](https://github.com/Cid-oe/omarchy)**: Desktop subsystem integrations, single-flight screen recording concurrency controls, and scoped LocalSend firewall rules for private subnets.

### 4. Multimodal RAG & Knowledge Engineering
- **[ReelsIQ (Instagram Reels AI Organizer)](https://github.com/Cid-oe/instagram-reels-ai-organizer)**: Full-stack platform turning thousands of saved video bookmarks into a vector-indexed AI knowledge base. Built with FastAPI, Playwright (session-caching and rate-limit jitter), Whisper audio transcription, PostgreSQL + `pgvector`, and Next.js 14.
